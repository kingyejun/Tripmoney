# ✈️ 여행 자금 플래너

해외여행 경비를 예측하고, **얼마를 / 어떻게 모아서 / 어떻게 쓸지**까지 계산해 주는 웹앱입니다.
빌드 과정 없이 HTML + CSS + JavaScript만으로 동작합니다.

## 주요 기능
- **계획**: 목적지·기간·인원·스타일 입력, 실시간 환율 불러오기, 수수료·예비비율 설정
- **예산**: 항공·숙소·식비·교통·액티비티·쇼핑·준비비·수수료·예비비를 자동 계산(직접 수정 가능), 환율 변동 영향 분석
- **모으기**: 월/주/일 필요 저축액, 3가지 저축 방법 비교, 이상적인 저축선 대비 진행 상황, 목표 달성 예상일
- **쓰기**: 하루 예산(원화·현지 통화), 여행 중 지출 기록, 오늘 쓸 수 있는 금액, 일별/항목별 현황

## 계산 방식 (정확도)
- 현지에서 쓰는 항목은 `현지 통화 단가 × 인원 × 일수 × 환율`로 계산하므로 환율이 바뀌면 예산도 같이 바뀝니다.
- 환율은 `open.er-api.com`에서 받아오며, 실패하면 내장 기준값(ECB 기준환율 2026-10-05 교차계산)을 사용합니다.
  - 대만달러·동은 내장값이 추정치이므로 '최신 환율 불러오기'를 한 번 눌러 주세요.
- 지출은 입력하는 순간의 **환율과 수수료를 함께 저장**해서, 나중에 환율이 변해도 기록한 금액은 바뀌지 않습니다.
- 시장 환율에는 은행 환전 마진이 없으므로 `환전·카드 수수료(%)`를 실제에 맞게 조정하세요. (기본 1%)
- 목적지별 단가(`app.js`의 `PRESETS`)는 참고용 평균값입니다. 항공권·숙소는 실제 가격을 입력하는 것을 권장합니다.

## GitHub Pages로 배포하기
1. GitHub에서 새 저장소를 만듭니다. (예: `travel-fund-planner`)
2. 이 폴더의 파일 4개(`index.html`, `style.css`, `app.js`, `README.md`)를 저장소 최상위에 올립니다.
3. 저장소의 **Settings → Pages**로 이동합니다.
4. **Source**를 `Deploy from a branch`, 브랜치를 `main`, 폴더를 `/ (root)`로 선택하고 **Save**를 누릅니다.
5. 1~2분 뒤 `https://<내 아이디>.github.io/travel-fund-planner/` 주소로 접속할 수 있습니다.

## 목적지·단가 수정
`app.js` 상단의 `PRESETS`에서 목적지별 단가를 수정하거나 새 목적지를 추가할 수 있습니다.
새 통화를 추가하려면 `CUR`과 `FALLBACK.map`에도 해당 통화 코드를 넣어 주세요.

## 데이터 저장
모든 데이터는 브라우저 `localStorage`에만 저장됩니다. 하단의 **백업 저장 / 백업 불러오기**로 JSON 파일을 내보내고 가져올 수 있습니다.
