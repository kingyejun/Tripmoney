# 같이모아 — 친구와 저축 챌린지

친구들과 같은 목표 금액을 정하고, 각자 모은 돈을 기록하며 진행률을 실시간으로 비교하는 웹앱이에요.
빌드 도구 없이 정적 파일만으로 동작하고, 데이터는 Firebase(무료 구간)에 저장돼요.

## 파일 구성
| 파일 | 역할 |
|---|---|
| `index.html` | 앱 전체 (화면 + 로직) |
| `firebase-config.js` | Firebase 설정값 (직접 채워야 함) |
| `firestore.rules` | DB 보안 규칙 (Firebase 콘솔에 붙여넣기) |

## 설정 순서 (약 10분)

### 1. Firebase 프로젝트 만들기
1. https://console.firebase.google.com 에서 프로젝트 생성
2. 프로젝트 개요 > **웹 앱(`</>`) 추가** > 표시되는 `firebaseConfig` 값을 `firebase-config.js`에 붙여넣기

### 2. 익명 로그인 켜기
**Authentication > 로그인 방법 > 익명** 을 사용 설정해요.

### 3. Firestore 만들기
1. **Firestore Database > 데이터베이스 만들기** (프로덕션 모드, 가까운 리전 선택)
2. **규칙** 탭에 `firestore.rules` 내용을 통째로 붙여넣고 **게시**

### 4. GitHub Pages로 배포
1. 이 폴더의 파일 3개를 저장소에 올리기 (`index.html`이 루트에 오도록)
2. 저장소 **Settings > Pages > Branch: main / (root)** 선택 후 저장
3. 배포 주소 `https://<아이디>.github.io/<저장소>/` 를 Firebase **Authentication > 설정 > 승인된 도메인**에 `<아이디>.github.io` 로 추가

## 친구와 쓰는 방법
1. 챌린지를 만들면 6자리 **초대 코드**가 생겨요.
2. 챌린지 화면의 **초대** 버튼으로 링크를 공유하면, 친구가 열어서 바로 참여할 수 있어요.
3. 각자 저금을 기록하면 모두의 화면에 실시간으로 반영돼요. 친구 카드의 이모지로 응원도 보낼 수 있어요.

## 알아둘 점
- **익명 로그인**이라 브라우저 데이터를 지우거나 다른 기기에서 열면 새 사용자로 인식돼요. 다음 단계로 Google 로그인 연결을 추천해요.
- 금액 기록은 서로 믿는 친구 사이를 전제로 해요. 본인 기록만 지울 수 있지만, 악의적으로 조작하는 건 규칙만으로 완전히 막지 못해요.
- 로그인한 사용자는 챌린지 문서를 읽을 수 있어요(코드로 찾기 위해). 민감한 정보는 넣지 마세요.
